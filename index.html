Étape 1 — Copier le modèle Google Sheet
Clique sur le lien ci-dessous pour dupliquer le modèle prêt à l'emploi
Le modèle contient déjà les deux onglets Locations et POI avec les bonnes colonnes. Tu n'as plus qu'à remplir tes données.
📋 Copier le modèle →
Étape 2 — Rendre le Sheet public en lecture
Dans ton Sheet : Partage → Accès général → "Toute personne ayant le lien" → Lecteur
⚠️ Indispensable — sans ça, l'app ne peut pas lire les données.
Aucune clé API requise : on utilise l'export CSV public de Google Sheets, qui fonctionne depuis n'importe quel navigateur sans blocage.
Étape 3 — Coller l'ID du Sheet
C'est la partie de l'URL entre /d/ et /edit
https://docs.google.com/spreadsheets/d/COLLE_ICI/edit
❌ Impossible de lire le Sheet. Vérifie que l'accès est bien "Toute personne avec le lien" et que l'ID est correct.
